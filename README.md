# FitGirl CLI 🎮

[English](#english) | [Português](#português)

## English

A command-line tool (CLI) built with Node.js to search and interact with games from the FitGirl Repacks website directly from your terminal.

### Features

* 🔍 Real-time search for games using the site's WordPress API.
* 📋 Interactive selection menu using arrow keys.
* 🚀 Lightweight, fast, and easy to run.

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/YanZ-afk-lab/fitgirl-cli.git
   cd fitgirl-cli
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

### Usage

Run the script in your terminal:
```bash
node CLI.js
```

Type the name of the game you want to search, use the arrow keys to select from the results, and press Enter.


2. Instala as dependências:
   ```bash
   npm install
   ```

### Como Utilizar

Executa o script no teu terminal:

Digita o nome do jogo que pretendes procurar, usa as setas para selecionar nos resultados e prime Enter.
